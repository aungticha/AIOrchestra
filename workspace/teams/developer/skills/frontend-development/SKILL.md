# frontend-development

1. Adhere to existing components and patterns. Verify contracts with the Backend.
2. Handle affected loading/empty/error/success states without expanding features.
3. Verify actual screens and modified interactions. Specify any remaining mocks before submitting for Review.
4. Consistently use the same libraries and templates throughout the project.
5. Web theme colors must be configurable via `global.css`.
6. For initial project setups, research and adopt popular project structures before starting.
