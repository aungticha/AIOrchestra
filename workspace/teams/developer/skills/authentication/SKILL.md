# authentication

1. แยกการยืนยันตัวตนออกจากการตรวจสิทธิ์ และยึดกลไกเดิมก่อนเพิ่มบริการ
2. ตรวจฝั่ง server สำหรับทุกเส้นทางที่ต้องจำกัดสิทธิ์ ไม่เชื่อค่าที่ client ส่งมาอย่างเดียว
3. ตรวจกรณีไม่มีสิทธิ์ session หมดอายุ และการไม่เปิดเผย secret/log ที่อ่อนไหว
