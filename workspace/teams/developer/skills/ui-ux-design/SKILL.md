# ui-ux-design

1. Review user goals, the existing UI, and relevant resources.
2. Create layouts and key states in a reviewable format. Do not redesign outside the requested scope.
3. Submit the design for User Acceptance before implementation. Specify handoff requirements for Frontend/QA.
