# accessibility

1. Use semantic elements, labels, and names readable by assistive technology.
2. Verify keyboard/focus navigation in modified interactions. Convey states using text or patterns in addition to color.
3. Specify actual tests performed and limitations. Do not claim certification-level compliance based solely on visual inspection.
