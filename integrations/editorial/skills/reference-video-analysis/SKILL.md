# Reference Video Analysis

## Producer: Find the Reference
- Read the brief, audience, platform, duration and style. Clarify critical missing information before searching.
- Prefer supplied references. Otherwise use an actually available search/browser tool to find 2–3 relevant public clips. Record source URL, title, useful time ranges, suitability and access limitations.
- Do not invent results or claim to watch a clip from its title/thumbnail. If tools or access are missing, report blocked and ask for an accessible clip or timestamped manual evidence.
- Discovery does not authorize downloading, uploading private footage, purchases or reusing copyrighted footage. Borrow the visual approach and create original content.

## Script / Storyboard Writer: Analyze and Adapt
1. Inspect the accessible video and audio with real tools. Record what was watched/heard and what remains unverified. Sampled frames alone cannot establish every cut, motion or sound.
2. Split the reference into timestamped shots. Distinguish shot size/angle, physical camera motion, editing zoom/reframe, transitions, speed changes, color, text, captions and audio cues.
3. Separate observations from inference. Describe an effect visually when its preset name/settings are unknown; never guess a CapCut preset ID or exact numeric value.
4. Propose an original timed storyboard based on the brief and available assets. Include the reference URL/time range supporting each creative decision and a practical CapCut implementation or approximation.

| Reference/time | Shot/angle/motion | Cut/effect/text | Audio | Evidence/confidence | New shot/CapCut approach |
|---|---|---|---|---|---|

## Handoff and Accept 1
- Present reference candidates, the recommended inspected source, storyboard, asset needs, optional Graphic/Audio work, and limitations before production.
- A selected reference must have an inspected storyboard; selecting a different source requires analysis and updated acceptance evidence first.
- Keep source URLs and timecodes. Do not start editing until the controller records explicit Accept 1. A changed reference or material storyboard change requires renewed approval.
- Editor executes the approved storyboard; QA compares the preview against it. This skill does not launch agents or connect CapCut by itself.
